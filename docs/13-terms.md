# 13. Словарь терминов

Одна и та же сущность называется по-разному в зависимости от рода занятий: у сервисной
компании это «заявка», у салона — «запись», на складе — «заказ». Тексты интерфейса берут
слово из словаря, а не вшивают его в разметку, поэтому смена отраслевой заготовки меняет
формулировки **внутри страниц**, а не только названия разделов.

## 13.1. Почему термин — это набор форм, а не строка

Русский язык требует падежей: «создать заявку», «срок заявки», «нет заявок». Из одного
слова эти фразы не собрать, поэтому термин описывается формами:

| Форма | Пример | Где нужна |
|---|---|---|
| `nom` | заявка | «Новая заявка» |
| `acc` | заявку | «Создать заявку» |
| `gen` | заявки | «Тема заявки» |
| `plural` | Заявки | заголовок раздела |
| `pluralGen` | заявок | «7 заявок», «Заявок нет» |

Термины: `ticket`, `client`, `site`, `team`, `item`, `warehouse` (`src/lib/terms.ts`).

## 13.2. Переопределения по отраслям

`PRESET_TERMS` задаёт только отличия, остальное берётся из словаря по умолчанию:

| Заготовка | `ticket` | `item` | `site` |
|---|---|---|---|
| Сервис и монтаж (по умолчанию) | заявка | позиция / «Товары» | объект |
| Салон услуг | запись | услуга / «Услуги и товары» | адрес |
| Складской учёт | заказ | номенклатура | объект |

## 13.3. Как пользоваться

**Серверная страница** получает словарь напрямую:

```tsx
const terms = await getTerms();
<PageHeader title={terms.ticket.plural} />
<Field label={`Тема ${terms.ticket.gen}`} />
```

**Клиентский компонент** берёт его из контекста (провайдер стоит в оболочке приложения):

```tsx
const terms = useTerms();
<button>{`Создать ${terms.ticket.acc}`}</button>
```

`capitalize()` делает первую букву заглавной там, где слово начинает фразу.

**Навигация** выводит названия разделов из словаря (`navLabelsFrom`); явные
переопределения в конфигурации установки (`labels`) имеют приоритет. Для нижней панели
на телефоне длинное название сокращается до первого слова.

## 13.4. Что уже переведено на словарь

Заголовки, подзаголовки, кнопки создания, шапки таблиц и пустые состояния на страницах
списка заявок, создания заявки и на главной, а также названия разделов навигации.

Остальные тексты (подробная карточка, складские экраны, сообщения сервисов) пока
содержат слова напрямую — они переводятся на словарь по мере доработки страниц.
Порядок тот же: взять `terms` и подставить нужную форму вместо вшитого слова.

## 13.5. Добавляя термин

1. Добавьте ключ в `TermKey` и формы в `DEFAULT_TERMS`.
2. При необходимости опишите отличия в `PRESET_TERMS` для нужных заготовок.
3. Подставьте формы в тексты страниц вместо вшитых слов.
