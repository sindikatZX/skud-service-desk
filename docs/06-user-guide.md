# 6. Руководство пользователя

Интерфейс адаптивен: на компьютере — боковое меню и таблицы, на телефоне — нижняя панель навигации и карточки. Приложение устанавливается на телефон: **Chrome/Android → меню → «Установить приложение»**, **Safari/iOS → «Поделиться» → «На экран Домой»**.

## 6.1. Диспетчер

1. **Приём заявки**: «Заявки → + Новая заявка». Выберите клиента и объект (если объекта нет — создайте его в карточке клиента), тему, тип (монтаж/ТО/ремонт/обследование), приоритет, срок. Можно сразу указать бригаду и время выезда — заявка получит статус «Назначена»/«Запланирована».
2. **Назначение и планирование**: в карточке заявки → вкладка «Назначение»: бригада, начало/окончание выезда, срок, приоритет. Список бригад показывает состав.
3. **Резерв оборудования под заявку**: вкладка «Резерв» — из остатков бригады заявки. Так монтажники видят, что именно нужно взять на объект.
4. **Контроль**: Главная — счётчики по статусам, просроченные, выезды сегодня. «Заявки» — фильтры по статусу/бригаде/поиск.
5. **Закрытие**: после того как бригада перевела заявку в «Выполнена» и клиент подтвердил — «→ Закрыта». При необходимости — «→ В работе» для доработки или «→ Отменена».
6. **Клиенты и объекты**: карточка клиента — объекты, история обслуживания; карточка объекта — установленное оборудование (с серийными номерами и ссылками на заявки) и история заявок.
7. **Отчёты**: статусы, типы, загрузка монтажников, клиенты, остатки у бригад, расход по бригадам/клиентам/заявкам за период.

## 6.2. Монтажник

1. Вход → «Заявки моей бригады». На телефоне — карточки с адресом и временем выезда.
2. Открыть заявку → «Статус» → «→ В работе» по прибытии.
3. **Фиксация работ**: вкладка «Работы» — описание, количество, минуты, исполнитель (участник бригады).
4. **Установка оборудования**: вкладка «Установка» — выберите серийную единицу (сначала показаны зарезервированные под эту заявку ★, затем свободные у бригады) или материал с количеством. Установленное сразу появляется в разделе «Установленное оборудование» заявки и в карточке объекта; остаток бригады уменьшается.
5. **Завершение**: «Статус» → напишите итог в поле комментария → «→ Выполнена». Комментарий сохраняется как результат работ.
6. «Моя бригада» — состав, автомобиль, текущие остатки (серийные единицы, материалы, резервы), последние движения.
7. При проблеме — «→ Приостановлена» с комментарием и/или комментарий в заявке.

## 6.3. Склад

1. «Склад» — остатки центрального склада: серийные единицы, материалы, резервы со склада; справа — сводка остатков у бригад.
2. **Поступление**: «Складские операции → Поступление». Для серийной номенклатуры — список серийных номеров (по одному в строке, опционально MAC через пробел). Для материалов — количество.
3. **Отгрузка бригаде**: выбрать бригаду, затем единицу или материал+количество. Отгруженное появляется в остатках бригады.
4. **Возврат**: в карточке бригады → «вернуть на склад» у единицы или форма возврата материалов.
5. **Списание**: брак/утеря с указанием причины.
6. **Журнал операций**: все движения с фильтрами по типу, бригаде, клиенту, заявке; у каждой записи — откуда → куда, бригада, клиент/заявка, инициатор.
7. **Расход**: «Отчёты → Расход оборудования и материалов: бригада → клиент → заявка» — что и куда фактически ушло.
8. **Жизненный цикл единицы**: клик по серийному номеру в любом месте системы → карточка единицы с таймлайном: поступление → отгрузка бригаде → резерв → установка на объекте (даты, ответственные, заявка, клиент).
9. «Номенклатура» — ведение каталога (артикул, категория, единица, признак серийного учёта).

## 6.4. Администратор

- «Сотрудники и автопарк»: создание пользователей с ролью, блокировка; автомобили.
- «Бригады»: создание бригады, добавление монтажников (до 3), назначение старшего, закрепление автомобиля. История состава и закрепления авто сохраняется.
- Все функции остальных ролей.

## 6.5. Клиент

- «Заявки» — только заявки своей организации, статусы и результаты работ.
- «+ Новая заявка» — на любой из своих объектов.
- Комментарии к заявке.
