# СКУД•Сервис — Self-Hosted Service Desk / FSM для СКУД и видеонаблюдения

Система управления заявками, бригадами монтажников и складским учётом движения оборудования (склад → бригада → резерв → установлено на объекте) с полным жизненным циклом серийных единиц.

Ключевое:
* **Заявки и выезды** — статусная модель с проверкой прав на каждый переход;
* **Склад** — серийный и количественный учёт, резервы под заявку, журнал операций;
* **Чат по заявке** — обсуждение диспетчера, бригады и склада; отдельно открытые сообщения для заказчика;
* **Справочники** — типы работ, приоритеты с SLA, категории оборудования, единицы измерения и **роли с настраиваемыми правами** заводятся из интерфейса;
* **PWA** — устанавливается на телефон, работает офлайн на чтение, мобильный интерфейс для бригад в поле;
* **Исправление ошибок** — записи можно удалять; удаление блокируется, только если оно разрушило бы историю (заявки, проводки, установленное оборудование).

**Стек:** Next.js 16 (App Router) · TypeScript · PostgreSQL 16 · Drizzle ORM · Tailwind CSS 4 · PWA · Docker Compose.

## Быстрый старт
```bash
cp .env.example .env    # задайте AUTH_SECRET и POSTGRES_PASSWORD
docker compose up -d --build
# http://localhost:3000 — демо-пользователи: admin@fsm.local / dispatcher@fsm.local / tech1@fsm.local / warehouse@fsm.local / client@fsm.local, пароль: password
```

## Что нового (мультисклад, документы, импорт из 1С, вложения)

- **Склады** (`/inventory`): несколько складов (центральный, транзитный, склады бригад, любые свои), документы «Поступление» (партии), «Перемещение», «Списание» с номерами и датами, журнал документов `/inventory/documents`.
- **Номенклатура** — дерево папок как в 1С, «Только в наличии», массовые действия по галочкам, импорт CSV из «1С:Торговля и Склад 7.7» (артикул не обязателен).
- **Импорт CSV** доступен во всех справочниках (кнопка «Импорт CSV», шаблон скачивается там же).
- **Чат заявки** — вложения любых типов с безопасной выдачей (см. `src/lib/services/attachments.ts`). Каталог файлов — `UPLOAD_DIR` (в Docker — том `uploads`).
- **Моя учётная запись** (`/profile`) — смена ФИО, телефона, логина и пароля.
- Администратор может вернуть закрытую заявку в работу.

Подробности — в `CHANGELOG.md`.
